# Aurum

Aurum is a Minecraft plugin designed to enhance the gaming experience with a variety of casino games and cosmetics. It includes features like coinflip, roulette, crash, and jackpot games, as well as customizable kill and death effects, and titles. The plugin integrates with economy providers and offers a comprehensive database system to manage player data.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your server to load the plugin.

## Use

1. Use the `/casino` command to open the casino menu and access various games.
2. Use the `/cosmetics` command to open the cosmetics menu and customize your kill and death effects.
3. Enjoy the enhanced gaming experience with Aurum.
